# Ресторан «Кам’яниця» — сайт з онлайн-бронюванням

Статичний сайт на HTML, CSS та JavaScript. Без встановлення чогось додаткового.

## Запуск
Відкрийте `index.html` у браузері (подвійний клік) або у VS Code встановіть розширення Live Server і натисніть Go Live.

## Як працює бронювання
- Обирається дата, кількість гостей і вільний час.
- Столик зайнятий 2 години, всього 6 столиків.
- Бронювання зберігаються у браузері (localStorage). Це демо без сервера: щоб бронювання бачив ресторан, потрібен бекенд.

## Що змінити під себе
Назва, адреса, меню — у `index.html`. Графік, кількість столиків і тривалість — на початку `script.js`. Кольори — на початку `style.css`.
